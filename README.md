📦 Supply Chain Analytics Dashboard

An end-to-end Supply Chain Analytics Dashboard built using SQL and Power BI to analyze inventory, manufacturing, logistics, suppliers, and revenue. The dashboard provides interactive visualizations and business insights to support data-driven decision-making.

 📌 Project Overview

This project focuses on analyzing the complete supply chain process by combining SQL for data analysis and Power BI for dashboard development. The dashboard helps identify business trends, monitor operational performance, and generate actionable insights.

📈 Key Business Insights

- Skincare products generated the highest revenue.
- Cosmetics maintained the highest average stock level.
- Supplier 4 recorded the highest manufacturing cost.
- Mumbai had the longest manufacturing lead time.
- Air transport showed the highest shipping cost.
- Sea transport had the longest average shipping time.
- Carrier B processed the highest order quantity.
